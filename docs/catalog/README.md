## How to view

- **On GitHub:** browse `template-catalog-report/assets/*/full-page.jpg` directly, or download `template-catalog-report.html` (GitHub won't render raw HTML inline).
- **Locally / offline:** download `template-catalog-report-bundle.zip`, unzip, open `template-catalog-report.html`.
- **In the EMA preview tab (per session):** the same bundle is also extracted under
  `content/template-catalog-report-bundle/` (git-ignored) and served by the local dev server.
