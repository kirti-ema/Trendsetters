# Overview

## Identity

- **Project:** Trendsetters — a website built with **Adobe Edge Delivery Services (EDS)**
  for AEM Sites, authored in **DA.live** (document authoring).
- **Based on:** [`adobe/aem-boilerplate`](https://github.com/adobe/aem-boilerplate).
  Follow the boilerplate's coding style and add functionality per project needs.
- **Repository:** `github.com/kirti-ema/Trendsetters` (default & production branch: `main`).
- **Migration source:** `https://wknd-trendsetters.site/` (starting page: `/about-us`).

## Tech stack

- Edge Delivery Services for AEM Sites (docs: https://www.aem.live/).
- Vanilla JavaScript (ES6+) — **no transpiling, no build step**.
- CSS3 (Grid, Flexbox, Custom Properties) — **no Tailwind / CSS frameworks**.
- HTML5 semantic markup generated by the aem.live backend, decorated by project code.
- Node.js tooling only for linting (ESLint Airbnb base + Stylelint standard).

## Setup / common commands

```sh
npm install                                         # dependencies (lint tooling only)
npx -y @adobe/aem-cli up --no-open --forward-browser-logs   # local dev on :3000
npm run lint          # eslint + stylelint — run before committing
npm run lint:fix      # auto-fix
```
